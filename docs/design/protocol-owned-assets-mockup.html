① Decide first

What do we call it?

I looked at how serious protocols name this. Three real patterns, one recommendation.

My recommendation

Protocol Reserves

Says what it is with zero jargon. "Reserves" reads as strength and prudence — money set aside, not money at play. It's the word central banks and serious treasuries use, and it carries no promise of return. Used by Frax, Sky/MakerDAO, Reserve. Pairs naturally with the honest caveat underneath.

Runner-up

What the Protocol Owns

Plain English, impossible to misread, very "proof-first". Slightly long as a section title, and it repeats the wording already used on /contracts — which is fine if you want one voice everywhere.

Runner-up

Treasury

The crypto-native default (Optimism, ENS, Nouns, karpatkey all use it). Instantly understood — but it's also the most crowded word, and it slightly implies a governance body that spends it.

Rejected on purpose: "Holdings" (sounds like a portfolio you trade), "Backing" (implies the token is redeemable against these assets — chain-refutable and a promise we never make), "Assets Under Management" (implies we manage other people's money — the exact wrong signal).

④ The intelligence you asked for

You buy Chainlink tomorrow → one line

The table is driven by a registry, not hand-written per coin. Adding an asset is one entry; the logo, the price feed, the row, the share bar and the total all follow automatically. I verified on-chain that a Chainlink price feed already exists on Avalanche — so this really is one line.

// artifacts/api-server/src/data/trackedAssets.ts
export const TRACKED_ASSETS = [
  { key: "AVAX",  kind: "native", decimals: 18, feed: FEEDS.avaxUsd, logo: "avax", order: 1 },
  { key: "BTC",   kind: "erc20",  decimals: 8,  token: BTCB, feed: FEEDS.btcUsd, logo: "btc",  order: 2 },
  { key: "ETH",   kind: "erc20",  decimals: 18, token: WETHE, feed: FEEDS.ethUsd, logo: "eth", order: 3 },
  { key: "USDC",  kind: "erc20",  decimals: 6,  token: USDC, feed: "PEGGED_USD", logo: "usdc", order: 4 },

  // ↓ the ONLY thing you add the day you buy LINK. Everything else is automatic.
  { key: "LINK",  kind: "erc20",  decimals: 18, token: LINKE, feed: FEEDS.linkUsd, logo: "link", order: 5 },
];

The logo library ships ahead of you. I vendor the top 50 by CoinMarketCap rank as local SVG files (public/coins/<symbol>.svg) — no external server is ever called, the page keeps working offline, and nothing leaks who visits us. A coin with no logo falls back to a lettered disc rather than a broken image. So the day you buy anything in the top 50, the logo is already there.
