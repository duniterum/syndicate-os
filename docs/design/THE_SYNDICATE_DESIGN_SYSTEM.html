The Syndicate · design system

One language, every surface.

This is the single source of truth for how The Syndicate looks — desktop and mobile. Every page is built FROM this, never patched into it. Benchmarked against world-class fintech/crypto and product systems (Stripe, Linear, Revolut/Kraken/Binance patterns) and grounded in the real tokens in index.css. If a surface disagrees with this file, the surface is wrong.

01 · Fonts & roles

Three voices, one job each.

The single most-broken rule was font mixing (mono on prose). Locked here, and guard-enforced.

Instrument Serif

Display & headings — only

Page titles and section headings. The expressive, editorial voice. Never on body text, labels, or numbers.

Work Sans

All body, labels & stats

Every sentence, description, UI label, button, and stat number. The default. If unsure, it's Work Sans.

IBM Plex Mono

Data & code — sparingly

On-chain values, addresses/hashes, code, and short UPPERCASE eyebrow labels. Never a sentence.

✓ Do
  • 0x03e…c6d0, 600 XP, 14 seats → mono (data)
  • THE SEASON POT → mono (uppercase eyebrow)
  • "Public, pseudonymous — your rank never drops." → Work Sans (prose)
✕ Don't
  • "Public, pseudonymous — your rank never drops." in mono (the /season patchwork)
  • 600 a stat number in serif
  • Mono for any multi-word mixed-case sentence, at any size

02 · Type scale (fluid, desktop → mobile)

One modular scale, it flexes itself.

Every size is a clamp() token — it scales smoothly from mobile to desktop, preserves zoom (WCAG 1.4.4), and never drops below the 12px readability floor. Use the token, never an arbitrary text-[13px].

Display--text-display · 38→68px · hero only
Heading 1--text-h1 · 30→48px · page title (serif)
Heading 2--text-h2 · 23→34px · section head (serif)
Heading 3--text-h3 · 19→25px · card title (Work Sans 600)
Body — the reading voice, 1.55 line-height, capped at 68ch.--text-body · 16→18px
Label — form & UI labels.--text-label · 13px
CAPTION · EYEBROW · DATA--text-caption · 12px FLOOR — never smaller

Line-height: headings 1.04–1.25 · body 1.55–1.6. Stat figures use Work Sans 600 + tabular-nums, size by importance (big = the figure you came for, small/muted = secondary).

03 · Spacing — the 8pt grid

Everything lands on 4/8.

Every margin, padding, gap, and height is a multiple of 4 (mostly 8): 4·8·12·16·24·32·48·64·96. This is what makes unrelated sections feel like one system. Section vertical padding is its own fluid token.

04 · Color roles (meaning, not decoration)

Each color means one thing.

A color is a signal. Gold is never "live"; cyan is never "identity". Consistency of meaning is the point.

Gold — identity

Seat · membership · the ONE primary action. Scarce by design.

Cyan — live / verified

Live reads, "verified on-chain", proof links, the heartbeat.

Green — success

OK · gross grows · positive confirmation.

Amber — caution

Attention / paused. Hue-shifted off gold so it never reads as identity.

Avalanche red

The AVAX chain indicator ONLY. Never a generic accent.

Neutrals

Command-room near-black surfaces · muted text for the secondary layer.

05 · Layout — edge-to-edge, no fixed cap

Fill the screen. Read at a measure.

✓ The law
  • Frame = w-full + px-4 sm:px-6 lg:px-8 — header, body, footer share the same edges. No container mx-auto, no fixed max-w-5xl page cap.
  • App/data fills width by multiplying columns — .auto-grid = auto-fit minmax(300px,1fr).
  • Text is bounded by a relative measure — .measure = 68ch. The cap is the line length, never the page.
✕ The bug
  • A narrow centered column with big empty margins on a wide screen.
  • 2 cards stretched super-wide instead of multiplying to 4–6.
  • A fixed pixel/rem width cap on any page or chrome.

Guarded: guard-fluid-surface reds any new container mx-auto.

08 · Mobile — grade-AAA at every width

320 → 2560, one system.

✓ Rules
  • Body ≥16px on mobile; the fluid scale handles the rest. Lines 35–45 chars on phone.
  • Tap targets ≥44×44px (WCAG 2.5.5 AAA) — buttons, links, footer rows.
  • Columns stack; multi-column footers become tap-to-open accordions.
  • Safe-area padding (env()); never maximum-scale=1; no horizontal scroll — ever.
✕ Never
  • Sub-16px body on mobile; sub-12px anything readable.
  • 4 cramped footer columns on a phone.
  • A row that forces sideways scrolling.

09 · Copy — human words only

If a human wouldn't say it, don't write it.

✕ Kill these (developer-speak)
  • "read only" — meaningless to a human. If there's no action, it's read-only by definition — so don't say it.
  • "not wired" · "fail-closed" · "RPC" · "null" · "bytes32" · "adapter" · "slice"
✓ Say instead
  • Nothing (drop it) — or "Verify on-chain" / "Checking…" / "Not available right now".
  • Plain outcomes: "every figure is a live chain read", "sign from your own wallet".

Also settled: no gain-promise words (ROI/yield/guaranteed); no ABI field names in user copy; addresses render short-form; mono only on data, never a sentence.
